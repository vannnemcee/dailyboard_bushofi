# DailyBoard Evan

DailyBoard adalah website dashboard produktivitas harian yang dibuat sebagai **Tugas Akhir Semester JavaScript**. Website ini membantu pengguna mengelola tugas, catatan, informasi cuaca, dan kutipan harian.

🔗 **Website:**
https://vannnemcee.github.io/tugas_dailyboard_evan/

---

## 📚 Tugas Akhir Semester

Project DailyBoard dibuat untuk memenuhi tugas akhir semester dengan ketentuan:

* Membuat website DailyBoard menggunakan HTML, CSS, dan JavaScript.
* Mengimplementasikan fitur yang telah dipelajari selama satu semester.
* Menyimpan data menggunakan `localStorage`.
* Menggunakan API eksternal.
* Membuat website responsif di berbagai ukuran layar.
* Melakukan deployment website secara online.
* Membuat dokumentasi project melalui README.

---

## ✨ Fitur

- **Daftar**
  - Tambah, edit, dan hapus tugas.
  - Tandai tugas selesai.
  - Filter dan pencarian tugas.
  - Drag & drop urutan tugas.

- **Catatan**
  - Tambah, edit, dan hapus catatan.
  - Data tersimpan di browser.
  
- **Cuaca**
  - Mencari cuaca berdasarkan nama kota.
  - Menampilkan suhu dan kondisi cuaca.

- **Kutipan**
  - Menampilkan kutipan harian.
  - Refresh untuk mendapatkan kutipan baru.

- **Tema**
  - Light mode dan dark mode.
  - Pilihan tema tersimpan otomatis.

---

## 🚀 Cara Pakai

1. Buka website DailyBoard.
2. Tambahkan tugas pada bagian **Tugas**.
3. Tandai, edit, hapus, atau cari tugas sesuai kebutuhan.
4. Tambahkan catatan pada bagian **Catatan**.
5. Masukkan nama kota untuk melihat informasi cuaca.
6. Gunakan tombol tema untuk mengubah tampilan terang atau gelap.

## 📁 Struktur File

```text
tugas_dailyboard_evan/
│
├── index.html
├── style.css
├── script.js
├── tugas.js
├── catatan.js
├── api.js
├── storage.js
└── README.md
```

* `index.html` — Struktur utama website.
* `style.css` — Tampilan dan responsivitas website.
* `script.js` — Menghubungkan seluruh fitur.
* `tugas.js` — Logika fitur tugas.
* `catatan.js` — Logika fitur catatan.
* `api.js` — Mengambil data dari API.
* `storage.js` — Penyimpanan data dengan `localStorage`.
